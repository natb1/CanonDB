# /principal:interview

A principal entry point that grants **nothing of the notebook**. It is the one place the
principal is the answerer and the AI the questioner, and it is the user's own version of the
clean context: a draw of what the user holds counts only so far as nothing in the room put it
there. So the questioner has not read the notebook, holds no graph or export of it, and holds no
transcript of an earlier interview; it holds the root question alone.

A second draw dates the first. Asked again from nothing, the user may derive the same order
again, and what comes back twice the same way is the position rather than the draw; or may
derive something else, and the difference is the finding, never a reason to change the order in
the moment. The order changes only by the user's own hand, by dictation, after the reading and
from level ground.

## Before anything

- **A fresh session.** If this session has read the notebook document, a graph file, an export,
  a page of it, or a transcript of an earlier interview, stop and say so. The draw would not be
  clean, and nothing can make it so in this session.
- **The right trigger.** The run is offered at the annual sitting and when a dependent's end
  was founded or changed, and otherwise at a backstop that knows nothing of the moment. It is
  never run on the heels of a decision the root bears on: a draw taken right after a quarrel
  has the quarrel in the room. If the user says that is why they are here, say so, and offer
  the consult entry point instead, which reads the standing clauses and draws nothing.

## Procedure

**1 — The question.** `.principal/notebook.json` at the checkout's root names the project and
the canon file its root stands in (`canon`, a map from root to file under `canon/`). Read that
file for the root question alone: the question's own paragraph, and nothing an answer below it
says. That is all this run reads.

**2 — Put it.** Put the root question to the user in its own words and wait. The user answers
in the user's own words; the run writes nothing down for them.

**3 — Follow, from the admissions.** Each further question is drawn from what the user has just
said and from nothing else: a word the user used that could mean two things, a clause the user
stated that another of the user's clauses seems to cut against, an order the user named whose
members were not all placed. Never a question drawn from what the notebook says, which the run
has not read; never one that offers the user a formulation to accept; never one that names a
tradition. Stop when the user says the answer is complete, or when a question would only
restate what was already said.

**4 — The dictation.** Read back, in the user's words and in the user's order, what the user
said: the answer as a thesis, its clauses, the words it brought in. Ask once whether that is
what was said; correct it where the user says. Then print it as the dictation the user runs,
with the dictate entry point, in the checkout: a further answer on the root, recorded with
`assent: the principal's own prior, drawn again`, beside the one that stands. Whether it agrees
or diverges with the standing answer is read in that run, which holds the notebook, and never
here.

**5 — Keep nothing.** No transcript, no summary in a file, no memory note. The dictation the
user runs is the only record, and the user runs it.

## Attenuation

- **The questioner holds nothing of the notebook.** A session that has read any of it cannot
  run this, and says so rather than proceeding. Nothing checks that but the session's own
  account of what it has read.
- **Questions come from the admissions.** The one leak that cannot be caught by a script is a
  question that carries the questioner's reading of the clause: cut every question that tells
  the user what was meant.
- **The user's words stand.** The read-back is the user's words reordered, never improved. A
  word the user did not use is not in the dictation.
- **Agreement is not read here.** Whether the draw agrees with the standing answer is the
  dictate run's reading, with the notebook in the room; this run has no standing answer to
  read it against and does not guess.
- **No transcript, ever.** The interview is the user's and ends with the session.
